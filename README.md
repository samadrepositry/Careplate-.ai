# CarePlate — Public Demo

This is a **static demo only** of CarePlate Health Companion.

- No sign-in, nothing saves, no real health data.
- All data shown is fictional sample data (James Miller, 62, Chicago).
- The demo shows Today, Medicines, Plate, Check-in, Reports / Medical Records, and the informational Symptom Guide.
- It does not diagnose, detect disease, or advise changing medication. Emergency: call 911 (US), or 988 for thoughts of self-harm.

The full working CarePlate app stays private in Muse.
